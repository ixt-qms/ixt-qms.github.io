# IxT-QMS

**Inspect. Then Trust.**

Sitio web de IxT-QMS — consultoría y formación para la industria automotriz.

Aguascalientes, México · [ixt.qms@gmail.com](mailto:ixt.qms@gmail.com)

## Servicios

- **Launch Excellence** — asesoría en lanzamientos de nuevos modelos y arranques de producción (SOP Readiness, Safe Launch).
- **Technical Representation** — representación técnica en planta ante OEM, Tier 1, Tier 2 y Tier 3.
- **IxT-QMS** — plataforma de digitalización de procesos de calidad, incluida al contratar servicios.
- **Training** — formación presencial en planta: Safe Launch, Control de Campo, Kaizen, 8D y QA, Quality Control & SPC.
